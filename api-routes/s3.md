# S3 images

Confirmed origin: `https://api-asset-production.s3.amazonaws.com/`.

Known object URLs supplied in A24 responses follow `media/images/{object}`. The downloader initially retrieved the 701 inventoried image objects directly. The user subsequently requested deletion of all images; those files were deleted, and image downloading is now excluded. Only the source URL inventory is retained as project research evidence.

A tested request to `/?list-type=2&max-keys=2` returned an XML `AccessDenied` response, preserved at `data/s3-list-response.xml`. Public object reads and bucket listing are separate permissions. This test does not prove that the bucket contains only images, that it exposes every stored object, or that it stores full film/TV masters.

`data/assets.json` records exact known source URLs and the title slugs that referenced them. Schema: [`assets.schema.json`](../schemas/assets.schema.json). Optimized `a24films.com/_next/image` URLs can embed the S3 origin; originals were downloaded directly from the supplied origin URLs.
